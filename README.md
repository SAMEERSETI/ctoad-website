# $CTOAD Website

This repository contains a simple landing page for the $CTOAD meme coin project.

## Files

- `index.html` — landing page structure
- `styles.css` — styling and layout
- `script.js` — small script for the footer year

## Local preview

Open `index.html` in a browser, or serve the folder locally with any static file server.

## GitHub Pages

To publish this site with GitHub Pages:

1. Open the repository on GitHub.
2. Go to **Settings** → **Pages**.
3. Under **Source**, choose **Deploy from a branch**.
4. Select **main** and **/root**.
5. Save.

Your site will be published at:

`https://sameerseti.github.io/ctoad-website/`

## Notes

This is a starter landing page for branding and community promotion. You can later add real token links, wallet integration, or a full app stack.
